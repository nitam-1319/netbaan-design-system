01Purpose

A badge is a small read-only marker that labels, categorizes, or counts. It rides alongside the content it describes — a status on a row, a category on a card, a count on a tab. Because it is non-interactive, reach for a Chip when the user can select or remove it, and a Tag when it filters a data set.

Status signal
Conveys state — active, pending, failed — with a tone and label.
Category label
Tags an item with a type, plan, or classification.
Numeric count
Shows small counts on tabs and icons, capped at 99+.

10Icons & adornments

Badges take one optional adornment on the leading edge: a status dot for state, or a 12px icon for a category. The count badge drops adornments entirely. Keep to a single adornment so the badge stays compact and legible; adornment and label always share the badge's text color.

17React implementation
