01Purpose

A radio lets a user pick exactly one option from a fixed, mutually exclusive set. Selecting one always deselects the rest, so the group always resolves to a single answer. Reach for a Checkbox when several options may be chosen, and a Select when the list is long enough to warrant a collapsed menu.

One from many
Exactly one option is active at a time within a group.
Few, visible choices
Best for 2–6 options that fit on screen without a menu.
Side-by-side compare
All options stay visible so users weigh them together.

10Icons & marks

The radio uses no glyphs — state is carried entirely by geometry. A concentric filled dot inside the ring means selected; an empty ring means not selected. The inner dot animates in with a subtle scale-up pop. This purely geometric language keeps radios visually distinct from checkboxes at a glance.

Selected — filled dot
Unselected — empty ring
