01Purpose

A select collapses a known set of mutually exclusive options into a single compact trigger. Use it when there are more than five options — below that, Radio buttons show every choice at once. For searching a very long list, reach for a Combobox; for many independent picks, a multi-select or Checkbox group.

Known finite list
Options are predefined and mutually exclusive — pick exactly one.
Space-efficient
Collapses 6+ choices into one row; the menu opens on demand.
Not for search
If users must type to filter, use a Combobox instead.
