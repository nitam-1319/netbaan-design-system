01Purpose

A checkbox represents an independent binary choice — turn a setting on, accept terms, or pick any number of items from a list. Reach for a Radio when options are mutually exclusive, and a Toggle when a change applies instantly without a save step.

Independent choices
Each box stands alone — checking one never unchecks another.
Multi-select lists
Pick zero, one, or many from a set with an optional select-all.
Deferred commit
Changes apply on submit, not instantly — unlike a Toggle.

10Icons & marks

The mark inside the box communicates state at a glance: a checkmark for checked, a horizontal bar for indeterminate (a partial selection in a group), and nothing when unchecked. Marks animate in with a subtle pop; they are decorative, since state is conveyed programmatically.

✓Checked — checkmark
Indeterminate — bar
Unchecked — empty
