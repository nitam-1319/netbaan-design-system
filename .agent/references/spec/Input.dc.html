01Purpose

An input collects a short, single-line value — a name, email, domain, query, or token. Use a Textarea for multi-line prose, a Select or Combobox for choosing from known options, and a Number Input for quantities. Every input carries a persistent, visible label.

Use when
A value is short, free-form, and not choosable from a list.
Always labelled
A visible label above; placeholder is a hint, never the label.
Validate on blur
Show errors after the user leaves the field, not on each keystroke.

10Icons & adornments

Adornments sit inside the field. A leading icon signals the field's type (search, domain, user); a trailing slot holds an interactive affordance — clear, password reveal, or a unit/prefix. Icons are decorative (aria-hidden); interactive trailing controls are real buttons with labels.
