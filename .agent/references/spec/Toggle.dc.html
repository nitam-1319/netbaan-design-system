01Purpose

A toggle switches a single binary setting on or off and applies the change instantly, with no separate save. Its sliding thumb mimics a physical switch, signalling an immediate, reversible state change. Reach for a Checkbox when the choice is submitted with a form, and a Radio for exclusive choice between options.

Instant effect
The change commits the moment the thumb slides — no save step.
System settings
Best for preferences and feature switches with a clear on/off.
Physical metaphor
The sliding thumb reads as a switch you flip, not a box you check.

10Icons & marks

Position carries state: thumb right on a filled track is on, thumb left on a muted track is off. Optional hairline glyphs inside the thumb — a check when on, a bar when off — add redundancy for users who don't perceive the color shift, and should be reserved for critical settings where the extra clarity is worth the visual weight.

✓On — thumb right, check
Off — thumb left, bar

17React implementation
Built on a native <button role="switch"> with aria-checked, so Space and Enter toggle it and screen readers announce on/off. The thumb slides via a CSS transform driven by the checked state — never by re-rendering position.
