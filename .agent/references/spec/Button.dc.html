01 Purpose

A button lets a user commit to a single, immediate action — submit, confirm, create, run, or cancel. It is not for navigation between pages (use a Link) or for toggling persistent state (use a Switch or Toggle). If the label reads like a destination rather than a verb, it should probably be a link.

Use when
An action changes data, submits a form, or triggers a process.
One primary per view
Reserve the filled Primary variant for the single most important action.
Verb-first labels
“Run scan”, “Export”, “Renew” — concise, action-led, sentence case.

10 Icons

Icons are optional and always paired with a label except in the dedicated icon-only variant. Use a leading icon to reinforce the action, a trailing icon only for direction (→) or disclosure (▾). Icon sizing tracks the label: 1em, optically centered, with a fixed gap token.

Icon-only buttons must carry an aria-label and a Tooltip.
