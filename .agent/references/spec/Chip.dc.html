01Purpose

A chip is a compact, interactive token representing a discrete piece of information the user can act on — a filter to toggle, a value entered into a field, a selectable option, or a removable entry. It is the interactive counterpart to the read-only Badge. Reach for a Badge when nothing can be clicked, and a Button for a primary page action.

Filter
Toggles a facet on or off in a result set.
Input
A committed value in a multi-entry field, removable.
Choice
A selectable option in a single or multi-select set.
Assist
A suggested action or entity, tap to act.

10Icons & adornments

A chip may carry a leading adornment — an avatar, category icon, or a check that appears when selected — and a trailing remove affordance. The remove target is its own focusable button, distinct from the chip body, so a chip can be selectable and removable at once without the two actions colliding.

17React implementation
A selectable chip is a <button role="checkbox"> carrying aria-pressed. The remove affordance is a nested, separately-focusable <button> whose click is stopped from bubbling, so removing never also toggles selection.
