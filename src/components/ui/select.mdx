# Select

A form control for choosing one value — or several, with `multiple` — from a list of
options. Restored to `.agent/references/spec/Select.dc.html`. Built on the Base UI
`Select` primitive, so portalling, floating-engine positioning, typeahead, roving focus,
modal focus management, native form integration (`name` / `required` / `disabled`), and
outside-press / Escape dismissal are all handled for us.

## Overview

Use a select when the user must pick from a known, moderately sized set of mutually
exclusive options and the chosen value belongs in a form. The trigger shows the
current value (or a placeholder); the portalled listbox shows the options.

## When to use

- **Do** use it for a single choice from ~6–20 known options that is part of a form
  (severity, owner, plan, status).
- **Don't** use it for two or three options where all should be visible at once — use a
  `Radio Group` or `Segmented Control`.
- **Don't** use it for free-text-plus-filtering over a large list — use a `Combobox`.
- **Don't** use it for a list of commands/actions — use a `Menu`.

## Anatomy

1. **Select** — the root; owns `value` state (controlled `value` / uncontrolled
   `defaultValue`), `open` state, and form props (`name`, `required`, `disabled`,
   `multiple`).
2. **SelectTrigger** — the control that opens the listbox (`role="combobox"`); styled
   with the semantic `variant` (`outline` / `filled` / `flush`) and `size` (`sm` /
   `md` / `lg`) props. Renders a trailing chevron that rotates 180° while open.
3. **SelectValue** — renders the selected item's label, or a `placeholder`.
4. **SelectContent** — the portalled, positioned listbox with scroll arrows. It enters
   with the signature `animate-menu-in` on the shared `shadow-elevated` surface.
   Placement is semantic: `side`, `align`, `sideOffset`, `alignOffset`.
5. **SelectItem** — an option (`role="option"`); the selected row carries an accent tint
   and a check indicator; supports `disabled`.
6. **SelectGroup** / **SelectGroupLabel** — a labelled section of options.
7. **SelectSeparator** — a non-focusable divider between sections.

## Variants

- **Outline** (default) — bordered (`border-border-strong`) on the `--surface-2` field.
- **Filled** — a higher-contrast `--surface-3` fill for dense forms.
- **Flush** — underline-only (bottom border, no radius) for inline / minimal UIs.

## Sizes

The `size` prop scales the trigger: `sm` (32px), `md` (42px, default), `lg` (48px).

## States

Default, Placeholder (dim hint), Hover (border lifts to `--accent-strong`), Open / focus
(accent border + 3px `accent-soft` ring, chevron rotated, `--surface` background), Error
(`--destructive` border + ring via `aria-invalid`), and Disabled (50% opacity, menu can't
open). Each is demonstrated as a story.

## Behavior

- **Open/close:** click, `Enter`, `Space`, or `ArrowDown`/`ArrowUp` on the trigger
  opens the listbox with the selected item highlighted. Selecting an option sets the
  value and closes the listbox; `Escape` or an outside press closes without changing.
- **Controlled/uncontrolled:** mirrors Base UI — `value` + `onValueChange` for
  controlled, `defaultValue` for uncontrolled.
- **Forms:** set `name` to submit with a native form; `required` enforces a choice;
  `disabled` disables the whole control. The trigger reflects validity via
  `aria-invalid`, which drives the destructive ring.
- **Placeholder:** `SelectValue`'s `placeholder` shows in a muted color until a value
  is chosen (driven by `data-[placeholder]`).

## Accessibility

- Meets WCAG 2.2 AA: option text and the selected-row surface clear contrast in both
  themes; the placeholder uses `--muted-foreground` which holds 4.5:1 on the trigger.
- Roles are supplied by the primitive: the trigger is a `combobox` with
  `aria-haspopup="listbox"` / `aria-expanded`, the popup is a `listbox`, and items are
  `option`s with `aria-selected`. Groups expose `aria-label` from their label.
- **Keyboard map:**

  | Key | Action |
  | --- | --- |
  | `Enter` / `Space` / `ArrowDown` / `ArrowUp` (on trigger) | Open the listbox |
  | `ArrowUp` / `ArrowDown` | Move highlight between options |
  | `Home` / `End` | First / last option |
  | `A`–`Z` | Typeahead to a matching option |
  | `Enter` / `Space` | Select the highlighted option, close |
  | `Escape` | Close without changing the value |

- Focus is managed by the primitive and returns to the trigger on close.

## Tokens

The trigger surface is `--surface-2` (`--surface-3` filled) with a `border-border-strong`
resting border; open / focus uses an `--accent` border and a 3px `--accent-soft` ring on
a `--surface` background. The popup uses `--popover` with a `--border-strong` ring and the
shared `--shadow` elevation (`shadow-elevated`); the selected / highlighted row uses
`--accent-soft` and the check uses `--accent-strong`. Invalid uses `--destructive`. No
hardcoded colors, spacing, or radii — tokens only.

## API

| Part | Key props | Notes |
| --- | --- | --- |
| `Select` | `value`, `defaultValue`, `onValueChange`, `open`, `defaultOpen`, `onOpenChange`, `name`, `required`, `disabled`, `readOnly`, `multiple` | Root; closed API |
| `SelectTrigger` | `variant` (`outline` \| `filled` \| `flush`), `size` (`sm` \| `md` \| `lg`), `disabled`, `render` | `role="combobox"` |
| `SelectValue` | `placeholder`, `children` (label formatter) | Shows current label |
| `SelectContent` | `side`, `align`, `sideOffset`, `alignOffset` | Portalled listbox |
| `SelectItem` | `value`, `disabled`, `label`, `render` | `role="option"` |
| `SelectGroup` / `SelectGroupLabel` | — | Labelled section |
| `SelectSeparator` | `orientation` | Divider |

The public API is **closed**: no `className` / `style` on any part. Customize through
the semantic `variant` / `size` props and place one-off layout in `Box` / `Stack`.
