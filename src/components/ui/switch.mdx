# Switch

An instant-apply on/off toggle. Built on the Base UI `Switch` primitive, which
renders an accessible `role="switch"` control with a paired hidden `<input>` for
form submission and full keyboard support. The track fills with the accent
gradient when on and the muted `--track` groove when off; the pure-white
thumb (inset 3px) slides across on toggle, all in AEGIS tokens.

## When to use

- **Do** use a switch for a setting that takes effect immediately ("Continuous
  monitoring", "Email alerts").
- **Don't** use a switch for choices that only apply after a Save — use a
  `Checkbox` in that case.
- **Don't** use a switch for mutually exclusive options — use a `Radio Group` or
  `Segmented Control`.

## Anatomy

1. **Track** — the pill (`role="switch"`) that fills with accent when on, muted
   when off, plus a hidden input for forms.
2. **Thumb** — the pure-white circle that slides between the two ends.
3. **Focus ring** — a 3px accent-soft halo on keyboard focus.
4. **Label** _(optional)_ — the setting name tied to the switch.
5. **Description** _(optional)_ — a secondary line stating what it controls.

## Sizes

| Size | Track | Thumb |
| --- | --- | --- |
| `sm` | 36 × 20 | 16 |
| `md` _(default)_ | 44 × 26 | 20 |
| `lg` | 52 × 30 | 24 |

## States

`off` · `on` · `hover` · `focus` (3px accent-soft ring) · `disabled` (45%
opacity, not-allowed) · `error` (`isInvalid` danger ring for an invalid required
switch) · `loading` (thumb spinner, locked, `aria-busy`).

## Behavior

| Trigger | Result |
| --- | --- |
| Click / tap | Toggles state, fires `onCheckedChange`. |
| `Space` / `Enter` | Toggles when focused. |
| `loading` | Shows a thumb spinner and locks the switch (`aria-busy`). |
| `disabled` | Non-interactive at 45% opacity. |

Controlled via `checked` + `onCheckedChange`; uncontrolled via `defaultChecked`.
Use `showIcons` to render a check (on) / bar (off) glyph in the thumb so state is
never conveyed by colour alone.

## Accessibility

- Exposes `role="switch"` with `aria-checked`; a single natural `Tab` stop.
- Always give it a name — pass `label`, wrap in a `<label>`, or set `aria-label`
  / `aria-labelledby`.
- Optional thumb glyphs and the announced `aria-checked` convey state without
  relying on colour.
- Focus shows a 3px accent-soft ring with ≥3:1 contrast.

## Design tokens

| Token | Applies to |
| --- | --- |
| `--track` | Off track (muted groove) |
| `--accent` → `--accent-strong` | On-track gradient |
| `white` | Thumb |
| `--accent-soft` | Focus ring |
| `--destructive` | Invalid-required (error) ring |

## API

Closed API — `className` and `style` are not accepted. Polymorphism via `render`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean` | — | Controlled on/off state. |
| `defaultChecked` | `boolean` | `false` | Uncontrolled initial state. |
| `onCheckedChange` | `(checked, details) => void` | — | Fires immediately on toggle. |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Track size. |
| `showIcons` | `boolean` | `false` | Check / bar glyphs inside the thumb. |
| `loading` | `boolean` | `false` | Thumb spinner, locked, `aria-busy`. |
| `error` | `boolean` | `false` | Danger ring for an invalid required switch. |
| `disabled` | `boolean` | `false` | Inert, non-interactive state. |
| `label` | `ReactNode` | — | Setting name (renders the label row). |
| `description` | `ReactNode` | — | Optional secondary helper line. |
| `name` / `value` | `string` | — | Form submission identity. |
