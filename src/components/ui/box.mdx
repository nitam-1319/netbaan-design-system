# Box

The lowest-level layout primitive in AEGIS. `Box` renders a `div` by default but
is fully polymorphic through Base UI's `useRender`, so it can become any element
or compose with another component via the `render` prop. It applies no styling of
its own — it exists to be the single, consistent building block that `Stack`,
`Grid`, and `Container` are built on.

## When to use

- **Do** reach for `Box` when you need a neutral, polymorphic wrapper and want a
  `data-slot` hook for targeting.
- **Do** use the `render` prop to change the tag (`<section>`, `<ul>`, `<nav>`) or
  to merge props onto a child component instead of adding a wrapper `div`.
- **Don't** try to pass `className`/`style` to `Box` — its API is closed. Put the
  token utilities on the element you hand to `render`, or reach for `Stack`/`Grid`/
  `Container` for token-driven layout.
- **Don't** use `Box` where a more specific primitive (`Stack`, `Grid`,
  `Container`) already expresses the intent.

## Anatomy

1. **Box** — a single element (a `div` unless `render` replaces it) carrying
   `data-slot="box"`, with the `render` element's own props merged in by `useRender`.

## Behavior

- Without `render`, `Box` outputs a `div`.
- With `render={<tag />}` (a React element) or a render function, `Box` outputs
  that element instead, merging the render element's own `className`, `style`,
  event handlers, and `ref` with the props `Box` forwards via `useRender` — no
  extra DOM node is introduced. `Box` itself forwards no `className`/`style`.

## Accessibility

- `Box` has no implicit role and adds no ARIA. Choose a semantic element through
  `render` (`<nav>`, `<section>`, `<ul>`, …) so the correct role is exposed.
- Keyboard: not focusable by itself; interactive children own their own focus.

## Design tokens

`Box` sets no tokens directly. Any surface, text, border, or spacing comes from
the token utilities on the element you pass to `render`, or from `Stack`/`Grid`/
`Container`.

| Token | Applies to |
| --- | --- |
| _(none by default)_ | Set on the `render` element or a higher-level primitive |

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `render` | `ReactElement \| (props, state) => ReactElement` | `<div />` | Element or render function to output instead of a `div`. |
| `...props` | `Omit<ComponentProps<"div">, "className" \| "style">` | — | Native attributes spread onto the rendered element. The API is closed: `className`/`style` are not accepted — style the `render` element instead. |

Every rendered element carries `data-slot="box"`.
