# Mini Location Map

The locator strip that opens an IP card: a dark regional map centred on one
address, with a pulsing marker and a chip naming the place.

## Overview

The map is location **evidence**, not decoration. A reviewer has to be able to tell
which country an address sits in, which is why **country borders are a required
layer** — a render showing only sea and a land silhouette fails the job.

It is the sibling of **Screenshot Thumb** for the same card media slot, at the same
heights: a domain card shows what a host looks like, an IP card shows where it is.

## Usage

- **Do** pass real `lat` / `lon`; the component centres its own projection on them.
- **Do** supply `geometry` from a build-time dataset and share one object across
  the whole grid, so it is parsed once per session.
- **Don't** guess a location when the data has none — leave `lat` / `lon` null and
  let the empty slot say so. An unplaceable IP must never be drawn somewhere
  plausible, least of all at 0,0.
- **Don't** use it as a general map. It frames one point at one scale; a country
  or region view is **GeoChoroplethMap**.

## Anatomy

A fixed-height band holding an `<svg>` of five stacked layers, an HTML marker
overlay (a 9px dot under a ping ring), and an optional bottom-start chip carrying
the place name plus the operator in mono.

Layers, bottom to top — all five are required:

| # | Layer | Paint |
| --- | --- | --- |
| 1 | Water | `--surface` |
| 2 | Graticule | `--border`, 40% |
| 3 | Land fill | `--surface-3` |
| 4 | Coastline | `--border-strong`, 1.1px |
| 5 | Country borders | `--muted-foreground`, 0.9px, 80% |

Land and coastline are the same paths — the fill stroked by its own outline — so
they can never drift out of register. Borders are drawn lighter than the coastline
so political divisions read first inside a landmass while the continent outline
stays calm.

## Projection

The component owns the projection: a Mercator centred on the address at a fixed
scale of 900 (one degree ≈ 15.7px). This has to happen at render time because every
card has a different centre, and Mercator's latitude is non-linear — a single
pre-projected frame cannot be re-centred by cropping without distorting both the
shape and the zoom.

Geometry is **not** owned here. The consuming app generates it at build time
(Natural Earth **50m**, simplified) and passes it in, so a ~300kB dataset stays out
of the sealed library and can be code-split by the app that needs it. 110m is not
sufficient: at this zoom it drops nearly every internal border.

## States

- **Placed** — map, pulsing pin, chip.
- **Unknown location** — no coordinates: the shared 135° hatch behind a `MapPinOff`
  icon and a caption, with **no pin at all**.
- **No place name** — map and pin, chip showing the operator alone; omitted
  entirely when that is missing too.

The band is a fixed height and `shrink-0`, so every state occupies the same strip
and a grid keeps one baseline.

## Performance

- Rings are clipped to a window around the centre **before** projecting — near a
  typical city that is roughly an eighth of the coastline.
- Path strings are memoised per coordinate, so a card re-rendering for any other
  reason never re-projects.
- Share one `geometry` object across the grid; do not parse it per card.

## Accessibility

- The canvas carries `role="img"` and the required `label`.
- The marker is `aria-hidden` — the place is already named in the chip and in the
  label, so announcing the pin adds nothing.

## RTL & motion

The marker is centred with physical `left`/`top` on purpose: geography is not a
reading order, so the map must not mirror. The chip and the empty state use logical
properties and do mirror. The ping obeys `prefers-reduced-motion`; the static dot
and ring remain.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Accessible name (required). |
| `lat` / `lon` | `number \| null` | — | Centre. Missing renders the empty slot. |
| `geometry` | `{ land, borders }` | — | Flat unprojected rings. |
| `city` / `countryCode` | `string \| null` | — | Chip place name. |
| `asn` | `string \| null` | — | Operator, mono, after the place. |
| `emptyLabel` | `string` | — | Caption for the empty slot (required). |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Media height (104 / 132 / 168px). |

The API is closed: `className` and `style` are not accepted.
