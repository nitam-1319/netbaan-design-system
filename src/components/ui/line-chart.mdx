# Line Chart

A config-driven line chart built entirely on the AEGIS chart foundation. Give it
a row array (`data`), the field that names each point (`xKey`), and one `series`
entry per numeric field to plot. It composes `ChartContainer` (geometry +
palette), `Axis` (x categories + linear y), `ChartLegend`, and its own SVG
line/area/dot marks — so colours and labels stay consistent across the legend
and the lines automatically.

## Overview

Line Chart shows how one or more numeric series change across an ordered set of
x categories (months, days, steps). Points sit at even fractions across the plot
— the first at the left edge, the last at the right — and the x-axis ticks line
up with them. The y-axis is a linear scale taken from `yDomain`, or derived from
the data extent and extended to include zero for a meaningful baseline.

## Usage

- **Do** use it for trends over an ordered dimension with a handful of series.
- **Do** give every series a clear `label`; it names the line in the legend and
  is how users who can't tell the colours apart identify it.
- **Do** fix `yDomain` when several charts must share a scale for comparison.
- **Don't** plot more than five series — the categorical palette has five
  distinct colours; beyond that, split into small multiples.
- **Don't** use a line chart for unordered categories — use a **Bar / Column
  Chart** instead.

## Anatomy

A `ChartContainer` (`role="group"`) wrapping an optional `ChartLegend` and a
`ChartPlot` (`role="img"`). Inside the plot: a left `Axis` (linear y, optional
grid), a `line-chart-marks` group holding one `line-chart-series` group per
series (`line-chart-area`, `line-chart-line`, and optional `line-chart-dot`
marks), and a bottom `Axis` whose explicit ticks align with the points.

## Behavior

- **Scale** — the y range is `yDomain` if given, else `[min(0, dataMin),
  dataMax]`. A flat series is padded so the line is visible.
- **Colours** — each series takes a palette slot by declaration order; pin one
  with `color: 1…5`.
- **Grid** — `showGrid` renders y gridlines through the left axis, so it applies
  only when `showYAxis` is on.
- **Static render** — scales, paths, axes, dots, and the legend are fully
  deterministic.

## Scope & limitations

This first Line Chart is a **static renderer**. A pointer/focus **hover
tooltip** (highlighting the nearest point and showing a `ChartTooltip`) is
browser-verification-heavy and is deferred to a follow-up, following the
honestly-scoped precedent in `DECISIONS.md` (DataTable, Combobox). Curve
smoothing is also out of scope — segments are straight. The `ChartTooltip`
surface already exists and will be wired in that follow-up.

## Accessibility

- The chart is announced through the container's accessible name (`label`) and
  the legend pairs each colour with a text label, so identity never rests on
  colour alone (WCAG 1.4.1).
- Because a hover tooltip is not yet present and hover content is not reachable
  by every user, **provide a text or data-table alternative** for the underlying
  values near the chart.
- The five chart tokens meet AA contrast against the surface in both themes; the
  line marks read at ≥2 px stroke.

## Design tokens

| Token / utility | Role |
| --- | --- |
| `--color-chart-1` … `--color-chart-5` | Series line, area fill, and dot stroke. |
| `--color-background` | Dot centre fill (so dots read on any line). |
| Axis / legend tokens | See `Axis` and `ChartLegend` guidelines. |

No colour or size is hard-coded in a mark; geometry comes from the container and
colour from the series palette.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Accessible chart name. Required. |
| `data` | `Record<string, ReactNode>[]` | — | Row data; one row per x point. |
| `xKey` | `string` | — | Field naming each point. |
| `series` | `{ key; label?; color? }[]` | — | One entry per line. |
| `yDomain` | `[number, number]` | data extent ∪ 0 | Fixed y range. |
| `area` | `boolean` | `false` | Fill under each line. |
| `showDots` | `boolean` | `false` | Dot at each point. |
| `showGrid` | `boolean` | `true` | y gridlines (needs `showYAxis`). |
| `showXAxis` / `showYAxis` | `boolean` | `true` | Render each axis. |
| `showLegend` | `boolean` | `true` when >1 series | Render the legend. |
| `yTickCount` | `number` | `5` | y-axis tick count. |
| `yFormat` | `(v: number) => ReactNode` | — | Format y ticks. |
| `width` / `height` | `number` | `640` / `320` | Coordinate size. |
| `margin` | `Partial<ChartMargin>` | axis-aware default | Plot gutter. |

The API is closed: `className` and `style` are not accepted.
