# Status Pill

A compact status marker: a coloured dot plus a short label on a soft, rounded
chip. Use it to show the state of an entity — "Active", "Pending", "Failed" — in
a table cell, list row, or header. The `tone` maps to AEGIS semantic colours,
and the dot inherits the label colour so the pair always agrees. An optional
`pulse` animates the dot for live or ongoing states.

## When to use

- **Do** use it to surface an entity's lifecycle or health state at a glance.
- **Do** keep the label to one or two words; the pill is a marker, not a
  sentence.
- **Don't** use it for counts — use a **Badge**.
- **Don't** use it for dismissible, user-generated labels — use a **Tag / Chip**.

## Tone

| `tone` | Meaning | Colour |
| --- | --- | --- |
| `neutral` | Inactive / draft / unknown | `muted` |
| `info` | In progress / informational | `primary` |
| `success` | Healthy / active / done | `success` |
| `warning` | Degraded / needs attention | `warning` |
| `danger` | Failed / error / blocked | `destructive` |

Never rely on colour alone — the label always carries the meaning.

## Sizes

| `size` | Height |
| --- | --- |
| `sm` | 20px |
| `md` | 24px (default) |

## States

Static (default) and `pulse` (the dot animates to indicate a live/ongoing
state, e.g. "Syncing", "Live").

## Behavior

- `StatusPill` is presentational; it has no interactive behaviour.
- The dot uses `currentColor`, so any tone keeps the dot and label in sync.

## Accessibility

- The label text conveys the status; the dot is decorative (`aria-hidden`), so
  meaning never depends on colour alone (WCAG 1.4.1).
- Contrast for every tone's text on its soft background meets WCAG AA in both
  themes.
- The `pulse` animation is a slow opacity fade and respects reduced-motion via
  the app's global motion settings.

## Design tokens

| Token | Applies to |
| --- | --- |
| `--muted` / `--muted-foreground` | Neutral fill / text + dot |
| `--primary` | Info tone |
| `--success` | Success tone |
| `--warning` | Warning tone |
| `--destructive` | Danger tone |

## API

`StatusPill` — renders a `<span>` chip with a status dot and label.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tone` | `"neutral" \| "info" \| "success" \| "warning" \| "danger"` | `"neutral"` | Semantic colour. |
| `size` | `"sm" \| "md"` | `"md"` | Chip size. |
| `pulse` | `boolean` | `false` | Animate the dot for live states. |
| `children` | `ReactNode` | — | The status label. |

The public API is closed: there is no `className` or `style` prop.
