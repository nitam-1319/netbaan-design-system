# Button

Triggers an action or event — submitting, confirming, opening, running. Restored to the AEGIS
reference: built on `@base-ui/react/button`, token-only, closed API, with the signature Primary
**beam**.

## When to use

- **Do** use `variant="primary"` for the single most important action in a view (it carries the
  animated beam). Reserve one Primary per context.
- **Do** use `secondary` / `soft` / `outline` / `ghost` for lower-emphasis actions, `destructive`
  for irreversible ones, and `link` for text-level navigation.
- **Don't** use a button for pure navigation when a real link is correct — use
  `render={<a href=… />}`.

## Variants

`primary` (beam + accent→surface gradient) · `secondary` (card + strong border, the default) ·
`soft` (accent-soft) · `outline` · `ghost` · `destructive` · `link`.

## Sizes

`sm` 32px · `md` 38px (default) · `lg` 46px · plus `icon` / `icon-sm` / `icon-lg`.

## States & behavior

| Trigger | Result |
| --- | --- |
| Click / `Enter` / `Space` | Fires `onClick`. Ignored while disabled or loading. |
| `loading` | Shows a spinner, holds the label, sets `aria-busy`, and blocks repeat clicks. |
| Hover | Brightness lift (Primary deepens its accent). |
| Active | Presses to `scale .98`. |
| Focus | 3px **accent-soft** ring. |
| `disabled` | 45% opacity, inert. |

## Accessibility

- Renders a native `<button>` (or the `render` element), so keyboard activation and roles are free.
- Focus-visible ring uses `--accent-soft` at ≥3:1 in both themes.
- Icon-only sizes require an `aria-label`.
- Loading sets `aria-busy`; motion honors `prefers-reduced-motion`.

## Design tokens

| Token | Applies to |
| --- | --- |
| `--accent` / `--accent-strong` | Primary beam + gradient |
| `--surface-2` | Primary inner surface |
| `--accent-soft` | soft variant + focus ring |
| `--card`, `--border-strong` | secondary/outline surfaces + borders |
| `--destructive` | destructive variant |
| `animate-beam-spin` / `animate-spin` | beam + loading spinner |

## API (closed)

`Omit<ButtonPrimitive.Props, "className" | "style"> & { variant, size, loading }` — no
`className`/`style`. Element swaps go through `render`; one-off layout via `Box`/`Stack`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | see above | `secondary` | Visual treatment. |
| `size` | see above | `md` | Control size. |
| `loading` | `boolean` | `false` | Spinner + `aria-busy`, holds the label. |
| `disabled` | `boolean` | `false` | Inert state. |
| `render` | `ReactElement` | — | Swap the rendered element (composition, not styling). |
| `onClick` | `(e) => void` | — | Activation handler. |
