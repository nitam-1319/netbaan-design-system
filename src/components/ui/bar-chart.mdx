# Bar / Column Chart

A config-driven column chart built on the AEGIS chart foundation. Give it a row
array (`data`), the field that names each category (`xKey`), and one `series`
entry per numeric field. Categories are laid out in evenly-spaced bands across
the x-axis (whose ticks are band-centred), and within each band the series are
drawn side-by-side (`grouped`) or `stacked`.

## Overview

Use a bar chart to compare a numeric value across a set of discrete, unordered
categories — findings by severity, signups by month, revenue by region. Bars
always grow from the zero baseline, which is what makes their heights directly
comparable; the y-axis is a linear scale from `yDomain`, or the data extent
extended to include zero (stacked charts measure per-category sums).

## Usage

- **Do** use it for comparison across discrete categories.
- **Do** choose **grouped** to compare series within each category, **stacked**
  to compare category totals while still showing the parts.
- **Do** keep the baseline at zero — truncating it exaggerates differences.
- **Don't** use a bar chart for a continuous trend over time with many points —
  use a **Line Chart**.
- **Don't** exceed five series; the categorical palette has five colours.

## Anatomy

A `ChartContainer` (`role="group"`) wrapping an optional `ChartLegend` and a
`ChartPlot` (`role="img"`). Inside the plot: a left `Axis` (linear y, optional
grid), a `bar-chart-marks` group with one `bar-chart-band` per category holding
its `bar-chart-bar` rects, and a bottom `Axis` with band-centred category ticks.

## Behavior

- **Bands** — the plot width is divided into equal bands; `bandPadding` (0–1)
  sets how much of each band the bars fill (default `0.7`). Grouped series split
  that width evenly; a stacked band is one bar column.
- **Scale** — y is `yDomain` if given, else `[min(0, dataMin), dataMax]`
  (grouped) or `[min(0, …), max(sum)]` (stacked). Negative values draw below the
  baseline.
- **Colours** — each series takes a palette slot by declaration order; pin one
  with `color: 1…5`.

## Scope & limitations

This first Bar Chart is a **static renderer**. A pointer/focus **hover tooltip**
is browser-verification-heavy and deferred to a follow-up (the `ChartTooltip`
surface already exists), per the honestly-scoped precedent in `DECISIONS.md`.
Horizontal bars are out of scope for this increment (columns only).

## Accessibility

- The chart is announced through the container's accessible name (`label`), and
  the legend pairs each colour with a text label, so identity never rests on
  colour alone (WCAG 1.4.1).
- Because a hover tooltip is not yet present, **provide a text or data-table
  alternative** for the underlying values near the chart.
- The five chart tokens meet AA contrast against the surface in both themes.

## Design tokens

| Token / utility | Role |
| --- | --- |
| `--color-chart-1` … `--color-chart-5` | Bar fill (via the series palette). |
| Axis / legend tokens | See `Axis` and `ChartLegend` guidelines. |

No colour or size is hard-coded in a bar; geometry comes from the container and
colour from the series palette.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Accessible chart name. Required. |
| `data` | `Record<string, ReactNode>[]` | — | Row data; one row per category. |
| `xKey` | `string` | — | Field naming each category. |
| `series` | `{ key; label?; color? }[]` | — | One entry per series. |
| `stacked` | `boolean` | `false` | Stack series instead of grouping. |
| `yDomain` | `[number, number]` | data extent ∪ 0 | Fixed y range. |
| `showGrid` | `boolean` | `true` | y gridlines (needs `showYAxis`). |
| `showXAxis` / `showYAxis` | `boolean` | `true` | Render each axis. |
| `showLegend` | `boolean` | `true` when >1 series | Render the legend. |
| `yTickCount` | `number` | `5` | y-axis tick count. |
| `yFormat` | `(v: number) => ReactNode` | — | Format y ticks. |
| `bandPadding` | `number` | `0.7` | Fraction of each band used by bars. |
| `width` / `height` | `number` | `640` / `320` | Coordinate size. |
| `margin` | `Partial<ChartMargin>` | axis-aware default | Plot gutter. |

The API is closed: `className` and `style` are not accepted.
