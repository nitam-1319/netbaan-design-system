# Radio Group

A set of mutually exclusive options where exactly one may be selected at a time.
Restored to the AEGIS reference: the sm/md/lg ring scale, the full state set, a
`size` prop, and built-in `label` + `description` slots. Built on the Base UI
Radio Group + Radio primitives, so the accessible `role="radiogroup"` /
`role="radio"` semantics, roving-tabindex keyboard navigation, and native form
integration come from the primitive; AEGIS supplies the circle-and-dot visuals
through tokens. Every color and radius comes from a token; the public API is
**closed** (no `className` / `style`).

## Overview

Use a Radio Group when a user must pick **one** value from a small, visible set
of options (typically 2–6).

## Usage

- **Do** use it for a short list of mutually exclusive choices that benefit from
  being visible at once (scan frequency, severity threshold, plan tier).
- **Do** pass each item a `label` (and optional `description`) so the whole row
  is a click target and has an accessible name.
- **Do** pre-select a sensible default so the group is never empty.
- **Don't** use a radio group for many options — use `Select` once the list grows
  past ~6 or needs scrolling.
- **Don't** use it for independent on/off choices — that is `Checkbox` (multiple)
  or `Switch` (instant apply).

## Sizes

`sm` 16px ring · `md` 20px ring (default) · `lg` 24px ring. The selected ring
draws a 2px accent border; the inner dot scales 7/9/11px with the ring.

## Anatomy

1. **Group** (`RadioGroup`) — the `role="radiogroup"` container; owns the selected
   value and lays the items out vertically or horizontally.
2. **Ring** (`RadioGroupItem`) — the circular control; renders `role="radio"` plus
   a hidden input for form submission.
3. **Dot** — the concentric inner fill, shown only on the selected item; it pops
   in with `animate-dot-pop`.
4. **Focus ring** — a 3px `accent-soft` halo on keyboard focus.
5. **Label / Description** _(optional slots)_ — the option text and an optional
   secondary line.

## Variants

Layout is controlled by `orientation`: `vertical` (default, stacked) or
`horizontal` (inline).

## States

Selected, Hover (border lifts to `accent-strong`), Focus (accent border + 3px
accent-soft ring), Error (`aria-invalid` → destructive border/ring), Disabled
(45% opacity, `not-allowed`), and Read-only (locked value).

## Behavior

- **Uncontrolled:** set `defaultValue` on the group.
- **Controlled:** pass `value` **and** `onValueChange` on the group.
- **Keyboard:** `Tab` moves focus into the group onto the selected (or first)
  item; `Arrow` keys move the selection between items (roving tabindex); `Space`
  selects the focused item.
- Disabling the group disables every item; a single item can also be disabled.

## Accessibility

- Roles: the group is `radiogroup`; each item is `radio` with `aria-checked`.
- Give the group an accessible name via `aria-label` or `aria-labelledby`.
- Keyboard map: `Tab` (enter/leave group), `↑`/`↓`/`←`/`→` (move selection),
  `Space` (select focused).
- Focus is always visible through the `accent-soft` focus ring; contrast holds in
  light and dark.

## Design tokens

| Token | Applies to |
| --- | --- |
| `--surface-2` | Ring interior surface |
| `--border-strong` | Unselected ring border |
| `--accent` / `--accent-strong` | Selected ring + inner dot (gradient) |
| `--accent-soft` | Focus ring |
| `--destructive` | Error (invalid) state |
| `animate-dot-pop` | Inner dot entrance |

## API (closed)

`RadioGroup` — `Omit<RadioGroupPrimitive, "className" | "style"> & { orientation }`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | Item layout direction. |
| `value` | `string` | — | Controlled selected value. |
| `defaultValue` | `string` | — | Uncontrolled initial value. |
| `onValueChange` | `(value, details) => void` | — | Fired when the selection changes. |
| `name` | `string` | — | Field name for form submission. |
| `disabled` | `boolean` | `false` | Disables the whole group. |
| `required` | `boolean` | `false` | Requires a choice before submit. |
| `readOnly` | `boolean` | `false` | Prevents changing the selection. |

`RadioGroupItem` — `Omit<RadioPrimitive.Root, "className" | "style"> & { size, label?, description? }`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | The value this item represents (required). |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Ring size. |
| `label` | `ReactNode` | — | Primary option text; renders a clickable row. |
| `description` | `ReactNode` | — | Optional secondary helper line. |
| `disabled` | `boolean` | `false` | Disables this item only. |
| `readOnly` | `boolean` | `false` | Locks this item's value. |

## Examples

- **Dark & Light:** switch the Storybook **Theme** toolbar — the ring, dot, and
  focus ring track the active theme.
- **RTL / Persian:** switch the **Locale** toolbar to فارسی; the horizontal layout
  and focus order mirror automatically because layout uses logical properties.
