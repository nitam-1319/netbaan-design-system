# Area Chart

A config-driven area chart built entirely on the AEGIS chart foundation. Give it
a row array (`data`), the field that names each point (`xKey`), and one `series`
entry per numeric field to plot. It composes `ChartContainer` (geometry +
palette), `Axis` (x categories + linear y), `ChartLegend`, and its own SVG
area/line/dot marks — so colours and labels stay consistent across the legend
and the bands automatically.

## Overview

Area Chart shows how one or more numeric series change across an ordered set of
x categories (months, days, steps), emphasising the volume under each line. A
single component covers the whole family through `stackMode`: `overlap`
(translucent bands from the zero baseline), `stacked` (opaque cumulative bands —
the **Stacked Area Chart**), and `expand` (the stack normalised to 100 % for
part-to-whole trends). Points sit at even fractions across the plot — the first
at the left edge, the last at the right — and the x-axis ticks line up with them.

## Usage

- **Do** use it to show a magnitude accumulating over an ordered dimension, or a
  part-to-whole split changing over time (`stacked` / `expand`).
- **Do** prefer a **Line Chart** when the message is the trend line itself and
  filled volume would only add clutter, or when series values cross often.
- **Do** give every series a clear `label`; it names the band in the legend and
  is how users who can't tell the colours apart identify it.
- **Don't** use `overlap` with many series — translucent fills muddy quickly;
  switch to `stacked`, or split into small multiples.
- **Don't** plot more than five series — the categorical palette has five
  distinct colours.

## Anatomy

A `ChartContainer` (`role="group"`) wrapping an optional `ChartLegend` and a
`ChartPlot` (`role="img"`). Inside the plot: a left `Axis` (linear y, optional
grid), an `area-chart-marks` group holding one `area-chart-series` group per
series (`area-chart-area`, optional `area-chart-line`, and optional
`area-chart-dot` marks), and a bottom `Axis` whose explicit ticks align with the
points.

## Variants

`stackMode` selects how series combine vertically:

- **overlap** (default) — each series is filled from the zero baseline and drawn
  translucent, so overlapping bands read through one another.
- **stacked** — series are cumulatively stacked into opaque bands; the first
  series sits at the bottom.
- **expand** — the stack is normalised so each x column sums to 1 (100 %).

## States

Static renderer — no interactive state yet (see Scope). Visual configuration:
`showLine`, `showDots`, `showGrid`, `showXAxis`, `showYAxis`, `showLegend`, and
`fillOpacity`.

## Behavior

- **Scale** — for `overlap` the y range is `yDomain` if given, else `[min(0,
  dataMin), dataMax]`. For `stacked` it is `[0, max column sum]`; for `expand`
  it is always `[0, 1]`. Stacked and expand read each datum as non-negative.
- **Colours** — each series takes a palette slot by declaration order; pin one
  with `color: 1…5`.
- **Grid** — `showGrid` renders y gridlines through the left axis, so it applies
  only when `showYAxis` is on.
- **Static render** — scales, paths, axes, dots, and the legend are fully
  deterministic.

## Scope & limitations

This Area Chart is a **static renderer**. A pointer/focus **hover tooltip**
(highlighting the nearest point and showing a `ChartTooltip`) is
browser-verification-heavy and is deferred to a follow-up, following the
honestly-scoped precedent in `DECISIONS.md` (DataTable, Combobox, Line Chart).
Curve smoothing is out of scope — segments are straight. The single-component,
three-mode design mirrors `BarChart` (grouped + stacked in one file); see
`DECISIONS.md` 2026-07-25.

## Accessibility

- The chart is announced through the container's accessible name (`label`) and
  the legend pairs each colour with a text label, so identity never rests on
  colour alone (WCAG 1.4.1).
- Because a hover tooltip is not yet present, **provide a text or data-table
  alternative** for the underlying values near the chart.
- The five chart tokens meet AA contrast against the surface in both themes; the
  top line reads at ≥2 px stroke.

## Design tokens

| Token / utility | Role |
| --- | --- |
| `--color-chart-1` … `--color-chart-5` | Series area fill, top line, and dot stroke. |
| `--color-background` | Dot centre fill (so dots read on any band). |
| Axis / legend tokens | See `Axis` and `ChartLegend` guidelines. |

No colour or size is hard-coded in a mark; geometry comes from the container and
colour from the series palette.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Accessible chart name. Required. |
| `data` | `Record<string, ReactNode>[]` | — | Row data; one row per x point. |
| `xKey` | `string` | — | Field naming each point. |
| `series` | `{ key; label?; color? }[]` | — | One entry per area. |
| `stackMode` | `"overlap" \| "stacked" \| "expand"` | `"overlap"` | How series combine vertically. |
| `yDomain` | `[number, number]` | data extent | Fixed y range (ignored for `expand`). |
| `fillOpacity` | `number` | `0.2` overlap / `0.85` stacked | Band fill opacity. |
| `showLine` | `boolean` | `true` | Stroke each band's top edge. |
| `showDots` | `boolean` | `false` | Dot at each point. |
| `showGrid` | `boolean` | `true` | y gridlines (needs `showYAxis`). |
| `showXAxis` / `showYAxis` | `boolean` | `true` | Render each axis. |
| `showLegend` | `boolean` | `true` when >1 series | Render the legend. |
| `yTickCount` | `number` | `5` | y-axis tick count. |
| `yFormat` | `(v: number) => ReactNode` | — | Format y ticks. |
| `width` / `height` | `number` | `640` / `320` | Coordinate size. |
| `margin` | `Partial<ChartMargin>` | axis-aware default | Plot gutter. |

The API is closed: `className` and `style` are not accepted.
