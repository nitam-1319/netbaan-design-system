# Grade Ring (A–F)

A letter-grade posture indicator — the **A/B/C/D/F** ring seen on security
scorecards. It composes the AEGIS **Radial Gauge** (`shape="ring"`), placing the
grade letter at the centre and mapping the grade tier to a semantic tone
(A → success … F → danger) and a representative ring fill.

## Overview

Executive security summaries condense posture into a single letter. Grade Ring
gives that letter a consistent, colour-coded home, with an optional precise
`score` driving the ring fill for the analysts who want the number behind the
grade.

## Usage

- **Do** use it for an overall posture/scorecard grade (asset, domain, org).
- **Do** pass `score` (0–100) when you have the underlying number — the ring
  fills to it; otherwise a per-tier fill is used.
- **Do** give a descriptive `label` ("Security grade") — the letter goes in
  `aria-valuetext`.
- **Don't** use it for an arbitrary percentage — that is **Radial Gauge** /
  **Scan Coverage Gauge**.

## Anatomy

A **Radial Gauge** ring (`data-slot="grade-ring"`, `data-grade`,
`role="meter"`) with the grade letter as the centre readout.

## Variants

Presentation is fixed; `size` (sm · md · lg) and `thickness` (thin · regular ·
thick, default `thick`) are inherited from Radial Gauge. Tone is derived from the
grade tier, not chosen.

## States

Presentational and deterministic — the same grade/score always renders the same
ring. Tones: A → success, B → accent, C/D → warning, F → danger.

## Behavior

- The leading letter of `grade` selects the tier, so "A+", "A", "A-" all resolve
  to the A tier; unknown letters fall back to F.
- `score` (clamped 0–100) drives the fill precisely; without it the tier's
  representative fill is used.
- The centre always shows the exact `grade` string (including +/− modifiers).

## Accessibility

- Exposes the ARIA `meter` role; the grade is announced via `aria-valuetext` and
  the fill via `aria-valuenow`, so it never depends on colour (WCAG 1.4.1).
- `data-grade` exposes the letter to tests and styling hooks.
- Give a meaningful `label`; it becomes the meter's accessible name.

## Design tokens

| Token / utility | Role |
| --- | --- |
| Radial Gauge `tone` (`success`/`accent`/`warning`/`danger`) | Ring arc + letter tier colour. |
| `stroke-surface-3` | Ring track. |
| `text-foreground` | Centre grade letter. |

No colour is hard-coded; every value comes from an AEGIS token.

## API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `grade` | `string` | — | Letter grade, e.g. "A+", "C-", "F" (required). |
| `score` | `number` | — | Numeric score (0–100) driving ring fill. |
| `label` | `string` | `"Grade"` | Meter accessible name. |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Ring scale. |
| `thickness` | `"thin" \| "regular" \| "thick"` | `"thick"` | Arc weight. |
| `showValue` | `boolean` | `true` | Render the grade letter in the centre. |

The API is closed: `className` and `style` are not accepted.

## Examples
