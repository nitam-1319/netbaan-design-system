# Tag / Chip

A compact, interactive token for filters, selections, and user-managed labels.
A Tag reads as content a user adds, toggles, or removes — which is what sets it
apart from `Badge`, a purely decorative status marker. It can carry an accent
`selected` state and an optional first-class dismiss button, enters with the
`chip-pop` animation, and maps every color to an AEGIS token. The public API is
closed (no `className` / `style`).

## Overview

Use a Tag for a discrete value in a set: an applied filter, an assigned label, a
selected option in a multi-select, or a keyword. Tags usually appear in groups
and wrap onto multiple lines.

## Usage

- **Do** use it for filters, labels, or multi-select selections the user can
  toggle, add, and remove.
- **Do** render it as a `<button>` (via `render`) when the whole chip toggles a
  filter or fires an action.
- **Do** provide `removeLabel` when the tag text alone doesn't make the dismiss
  action clear (e.g. `removeLabel="Remove us-east-1"`).
- **Don't** use a Tag as a static status marker — use `Badge`.
- **Don't** use a Tag as a primary action — use `Button`.

## Anatomy

1. **Container** — the pill body; the primary target for select or activate.
2. **Leading adornment** _(optional)_ — an icon or avatar, auto-sized per size.
3. **Label** — the token text: a value, facet, or entity name.
4. **Remove button** _(optional)_ — a trailing `×`, its own focusable control,
   shown only when `onRemove` is set.

## Sizes

`size` sets the height and padding: `sm` ≈ 22px · `md` ≈ 28px (default) · `lg` ≈
34px.

## States

- **Resting** — `--surface-3` fill, strong border, dim text.
- **Selected** — accent-soft fill, accent border and text (`selected`).
- **Hover** (resting) — the border and text lift toward the accent.
- **Focus** — a 3px `--accent-soft` ring with an accent border.
- **Disabled** — dimmed and non-interactive.

## Behavior

- A Tag is static unless made interactive. Pass `render={<button />}` to make the
  whole chip a control (toggle `selected`), or `onRemove` to add a dismiss button.
- `disabled` dims the tag and disables the dismiss button.
- Removal / selection state is owned by the consumer — the Tag reports intent;
  the parent updates its list.

## Accessibility

- The dismiss control is a native `<button>` with `aria-label` (`removeLabel`),
  focusable and operable with `Enter` / `Space`.
- When the chip itself toggles, render it as a `<button>` so it is keyboard
  operable; `selected` is exposed via `data-selected` for styling.
- Meaning is carried by the label text, never color alone.
- Focus is always visible via the `--accent-soft` ring in light and dark.

## Design tokens

| Token | Applies to |
| --- | --- |
| `--surface-3` / `--border-strong` | Resting fill + border |
| `--accent-soft` / `--accent-strong` | Selected fill, text, border, focus ring |
| `--track` | Remove-button backing (resting) |
| `--muted-foreground` / `--foreground` | Label + hover text |

## API

`Tag`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Padding + text size. |
| `selected` | `boolean` | `false` | Accent-tinted "on" state for filter / choice chips. |
| `onRemove` | `() => void` | — | When set, shows a dismiss button and fires on activation. |
| `removeLabel` | `string` | `"Remove"` | Accessible label for the dismiss button. |
| `disabled` | `boolean` | `false` | Dims and disables the tag + dismiss button. |
| `render` | `ReactElement` | `<span />` | Compose the element (e.g. render as `<button>`). |

The public API is closed: there is no `className` or `style` prop.

## Examples

- **Dark & Light:** switch the Storybook **Theme** toolbar; fills, text, and the
  focus ring track the active theme.
- **RTL / Persian:** switch the **Locale** toolbar to فارسی; the leading icon and
  trailing dismiss button swap sides automatically because spacing uses logical
  properties.
