# Avatar Group

A compact, overlapping stack of **Avatar**s for showing the people on a thread,
team, or shared resource. Pass `Avatar` elements as children; the group overlaps
them, rings each in the `background` colour so they read as separate, and — when
`max` is set — collapses the remainder into a "+N" chip.

## When to use

- **Do** use it to show membership or participation compactly (assignees,
  collaborators, attendees).
- **Do** set `max` when the list can grow, so the row stays a fixed width.
- **Don't** use it where each person needs a name or action beside them — use a
  **List** of avatars instead.
- **Don't** mix avatar sizes within one group; keep the child `Avatar` `size` in
  step with the group's `size`.

## Anatomy

1. **Group** — the overlapping flex row.
2. **Items** — each child `Avatar`, wrapped with a `background` ring for
   separation.
3. **Overflow chip** — a "+N" `muted` circle shown when more than `max` avatars
   are provided.

## Sizes

`size` (`xs` / `sm` / `default` / `lg` / `xl`) sets the overlap amount and the
overflow chip's text, matching the **Avatar** size scale (24 / 32 / 36 / 44 /
56px). Give the child `Avatar`s the same `size`.

## Behavior

- Children are rendered in order; when more than `max` are supplied, the first
  `max` show and the rest collapse into the overflow chip.
- Without `max`, every avatar is shown.
- The ring uses the `background` token so avatars separate against any surface.

## Accessibility

- Each child `Avatar` carries its own accessible name via its image `alt` or
  fallback text.
- The overflow chip has an `aria-label` ("N more") so the hidden count is
  announced.
- The group itself is presentational; give the surrounding context a label if
  the set of people needs one.

## Design tokens

| Token | Applies to |
| --- | --- |
| `--background` | Separator ring around each avatar |
| `--muted` / `--muted-foreground` | Overflow chip fill / text |

## API

`AvatarGroup` — overlaps its `Avatar` children with an optional overflow chip.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"xs" \| "sm" \| "default" \| "lg" \| "xl"` | `"default"` | Overlap + chip scale (match the child avatars). |
| `max` | `number` | — | Max avatars before collapsing into "+N". |
| `children` | `Avatar[]` | — | The avatars to stack. |

The public API is closed: there is no `className` or `style` prop.
